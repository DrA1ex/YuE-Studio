# YuE Studio UI 0.4.0-ui.2

The fork now includes upstream main through `69e85c7`, incorporating both commits
following the 0.4.0 release while retaining the advanced Studio interface.

## New in the Studio UI

- **Create → Hum a melody**, beside Audio: record up to 30 seconds, transcribe
  locally, review/edit the score in a dark review sheet, then choose **Continue
  from my melody** or **Use the complete melody**. Install the Melody component in
  Settings first. Microphone use has an explicit permission description.
- **More Options → Use score as** supports a complete melody or an opening to
  continue, including imported/pasted ABC. Continuations use the chosen maximum
  duration rather than being capped to a short source recording.
- The planner retains the exact opening tokens and appends the generated score.
- Neural Engine program compilation now has its own progress message rather than
  appearing to remain at weight loading.

Hum transcription uses the fork's existing queue/memory coordinator and pinned
SheetSage2 environment, with a distinct cached vocal-melody task. It does not run
Whisper, genre/style or vocal-separation stages. Normal cover analysis retains
those stages and their fallback behavior. Existing lyrics and style are preserved
when accepting a hum. Recordings have unique names; leaving the recording sheet
stops the microphone and obsolete permission callbacks cannot restart it.

## Downloads

- **YuE-Studio.dmg**: Apple Silicon, macOS 14+. App version 0.4.0, refreshed build.
  Ad hoc signed, **not Apple-notarized**. Replace the app in Applications; compatible
  installed runtimes and model downloads are reused.
- **YuE-Remote-0.4.0-unsigned.ipa**: unchanged companion from ui.1, arm64/iOS 18+.
  Must be signed/provisioned before device installation. The Xcode source is also
  included in the repository. No new iPhone behavior is introduced by this release.
- **SHA256SUMS.txt**: checksums for both binaries.

## Verification

- **248 Python tests, 34 subtests and 17 Swift tests passed**. Eleven optional
  CUDA/vLLM/reference-checkpoint cases skipped, no failures.
- Synthetic fixtures cover hum vocal prompts and cache reuse, skipping unrelated
  analyzers, exact opening/continuation token assembly, source-fidelity opt-out,
  instrumental openings, cover duration/metadata, safe recording discard, and
  compile-progress messages for cached versus uncached ANE programs.
- Release build, microphone entitlement/plist, strict deep signature, DMG integrity,
  mounted-app equality and packaged-source parity verified before publication.
- Companion archive is reused byte-for-byte from the previous verified release.

Microphone permission/recording, transcription accuracy on a real hum, physical
Neural Engine/iPhone inference and manual GUI interaction were not tested. The
synthetic checks do not certify those hardware-dependent behaviors.
