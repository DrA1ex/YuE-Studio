# YuE Studio UI 0.4.0-ui.1

The advanced Studio fork is now based on upstream **YuE Studio 0.4.0**, with its
custom cover workflow, audio-analysis components, library, player and storage
settings retained.

## Added

- **iPhone synthesis:** YuE Remote can provide a second Neural Engine on the local
  network, including migration from the GPU and local retry when the phone refuses
  or disconnects. In **More Options**, choose **GPU + Neural Engine** and enable
  **Use an iPhone’s Neural Engine**. Keep YuE Remote in the foreground. The first
  use transfers about 2.8 GB of weights; phone synthesis currently supports roughly
  2m40s of audio, subject to device/compiler limits.
- **Engine selection:** choose GPU-only or GPU + Neural Engine for Draft/Full
  generation and saved-token rendering.
- **Automatic titles and lyric writing:** fallback titles work without Apple
  Intelligence; the Lyrics sparkles button uses the on-device model when available
  on macOS 26+. Includes upstream's outro and previous-theme fixes.
- **Reliability:** background ANE compilation without loading, transient inference
  retry, and recovery/correlation for failed renders.

## Preserved from the advanced fork

Source-melody covers and fidelity controls; duration matching; independent
analysis components; Whisper with MLX/Transformers recovery; optional Demucs vocal
activity; genre/style inference; lyric structure and acoustic repetition evidence;
reusable analysis cache and safe clearing; waveform playback, seeking and volume;
library metadata, import/export and Trash actions; existing runtime/model reuse.

## Downloads and requirements

- **YuE-Studio.dmg** — macOS app, Apple Silicon, macOS 14+. Drag YuE Studio to
  Applications. Existing local runtime/models are reused when compatible.
- **YuE-Remote-0.4.0-unsigned.ipa** — iPhone/iPad companion, arm64, iOS 18+.
  **Unsigned: it must be signed/provisioned before installation.** Alternatively,
  open `app/YuERemote/YuERemote.xcodeproj`, select your development team and build
  for your device. Its increased-memory entitlement requires suitable provisioning.
- **SHA256SUMS.txt** — checksums for both binaries.
- Full source is available through GitHub's source archives for this tag.

The Mac app is **ad hoc signed, not Apple-notarized**. The companion's optional
Bench screen needs separately supplied benchmark models; these are not bundled.
Production synthesis receives programs from the Mac.
