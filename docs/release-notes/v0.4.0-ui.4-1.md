# YuE Studio UI 0.4.0-ui.4-1

This is the first release of the DrA1ex fork, based on **YuE Studio UI 0.4.0-ui.4**.

The changelog below contains only changes made in this fork after that base release. Upstream and parent-fork changes already included in 0.4.0-ui.4 are not repeated here.

## Highlights

### More reliable offline installs and updates

- Pinned YuE2 model revisions and made packaged startup local-only once the models are installed.
- Added verification and repair for missing or corrupt cached model files instead of trusting an existing model directory.
- Reused compatible installed runtimes across app updates instead of forcing a full setup pass.
- Refreshed bundled source locally when possible, avoiding unnecessary network access after updates.

### Practical audio import and export

- Imported audio is normalized to a stable 48 kHz PCM WAV before being added to the library.
- Finished songs can be exported as 320 kbps MP3.
- FFmpeg discovery now supports common Homebrew/MacPorts locations and `YUE_STUDIO_FFMPEG`.
- Setup installs FFmpeg through Homebrew when needed.

### Faster and clearer iPhone synthesis

- Reduced avoidable overhead in the initial iPhone weight transfer path.
- Kept Bonjour discovery on the normal LAN instead of opting into peer-to-peer Wi-Fi.
- Accepted partial TCP reads on iOS and streamed layer payloads without building an extra full-size copy in memory.
- Added visible diagnostics when a song falls back to the Mac because its required iPhone program bucket exceeds the supported row limit.
- Added explicit logs for the start and completion of the first synthesis-weight transfer.

### Configurable cover analysis

- Added a downloaded cover-model manager with exact model IDs, purpose, disk usage and per-component removal.
- Added cleanup for legacy `openai/whisper-small` downloads.
- Made cover-analysis stages independently configurable:
  - Lyrics transcription
  - Vocal-region detection with Hybrid Demucs
  - Genre classification
  - Detailed CLAP style analysis
- Added a lyrics backend selector: **Automatic**, **MLX Whisper**, or **Transformers Whisper**.
- Melody/score extraction remains the only required cover stage.
- Disabled stages are now genuinely skipped, including their preprocessing and model loading.
- Installing cover components now installs only what is enabled instead of downloading every optional model by default.

### Release builds

- Added GitHub Actions builds for the macOS DMG and unsigned iOS IPA.
- DMG and IPA are produced as separate artifacts with SHA-256 checksums.
- Release builds now run only for tags or explicit release workflows instead of every push to `main`.
