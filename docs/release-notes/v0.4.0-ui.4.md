# YuE Studio UI 0.4.0-ui.4

This release fixes the iPhone Neural Engine program generated for iOS 27 and assigns
independent songs to the Mac and iPhone for parallel synthesis.

## New in this release

- Remote Core ML attention uses the iOS 27 compatible tiled formulation and a new
  `coreml2` program-cache version. Existing model weights remain reusable.
- The Mac keeps the first song of a queue and the iPhone receives every second eligible
  song. A single song stays on the Mac; unsupported lengths and connection failures fall
  back to the Mac.
- YuE Remote reports rejected Neural Engine placement clearly and resets its session state
  after a failed program load.

## Downloads

- **YuE-Studio.dmg**: Apple Silicon, macOS 14+, ad hoc signed and not Apple-notarized.
- **YuE-Remote-0.4.0-ane-fix-unsigned.ipa**: arm64, iOS 18+, unsigned and requiring signing
  or provisioning before installation on a device.
- **SHA256SUMS.txt**: checksums for both release artifacts.

## Verification

- 17 synthetic Python tests passed for remote scheduling, program-cache migration and the
  existing Cover request path.
- Regenerated 1024×2048, 1536×2048 and 4096×4096 remote programs were fully assigned to
  the Neural Engine by Core ML on the development Mac; numerical outputs remained finite
  and tracked an independent float32 reference.
- macOS and iOS Release builds completed. The Mac app signature, DMG contents, IPA archive
  and final SHA-256 checksums were verified.

The generated programs were not executed on the physical iPhone during this release check.
The release targets iPhone 17 Pro Max on iOS 27.0; the first run compiles the new cached
program on the phone and reuses the already transferred weights.
