# YuE Studio UI 0.4.0-ui.3

This fork adds the voice-idea workflow across the macOS Studio and the iOS companion,
with the canonical `icons/YuE_icon.icon` artwork now shared by the iOS app icon.

## New in this release

- **iOS YuE Remote** keeps vocal ideas locally, records with a live input meter, and
  exposes the iOS microphone route picker.
- **Studio → Hum a melody** includes microphone selection, a corrected real-time level
  meter, and import of saved iPhone vocal ideas over the local network.
- Bonjour discovery uses `_yuevoice._tcp`; the iOS app advertises memo metadata and
  serves the recorded audio to the Studio.
- The unsigned iOS archive now embeds the complete `YuE_icon.icon` through Xcode's
  asset compiler, for iPhone and iPad.

## Downloads

- **YuE-Studio.dmg**: Apple Silicon, macOS 14+, ad hoc signed and not Apple-notarized.
- **YuE-Remote-0.4.0-unsigned.ipa**: arm64, iOS 18+, unsigned and requiring signing or
  provisioning before installation on a device.
- **SHA256SUMS.txt**: checksums for both release artifacts.
